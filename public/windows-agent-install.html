Cài đặt Windows Agent 1-Click

Chọn 1 trong 2 cách cực kỳ đơn giản dưới đây để kết nối máy tính Windows vào Dashboard:

🔌Cách 1: Chạy 1 dòng lệnh PowerShell

Mở PowerShell (Run as Administrator) trên máy Windows và chạy lệnh dưới đây. Cực nhanh, chỉ cần 30 giây!

powershell -NoProfile -ExecutionPolicy Bypass -Command "Invoke-WebRequest 'http://192.168.1.246:3000/install.bat' -OutFile $env:TEMP\install.bat; & $env:TEMP\install.bat"
  • Tự động tải file cài đặt
  • Chạy với quyền Administrator
  • Hoàn thành trong 30 giây

📥Cách 2: Tải file .BAT và chạy

Tải file cài đặt install.bat về máy, sau đó double-click để chạy. Tương thích 100% với Windows!

install.bat (100% tự động)
📥 Tải File install.bat
  • Double-click để chạy
  • Không cần terminal/PowerShell
  • Dễ dàng chia sẻ với người khác

📋 Hướng dẫn chi tiết (Cách 1: PowerShell)

1 Mở PowerShell với quyền Administrator

• Nhấn Win + R

• Gõ: powershell

• Nhấn Ctrl + Shift + Enter

💡 Lưu ý: Chỉ chạy với quyền Administrator thì mới hoạt động!
2 Copy & Paste lệnh PowerShell

• Click nút "COPY" ở trên để copy lệnh

• Click chuột phải trong PowerShell, chọn "Paste"

• Hoặc dùng Ctrl + V để paste

3 Nhấn Enter & Chờ cài đặt hoàn thành

• Nhấn Enter để chạy lệnh

• PowerShell sẽ tự động tải file cài đặt

• Quá trình cài đặt kéo dài ~30 giây

• Khi hoàn thành, bạn sẽ thấy thông báo: "HOÀN TẤT CÀI ĐẶT!"

✓ Máy tính của bạn đã được kết nối vào Dashboard!
4 Kiểm tra kết nối

• Truy cập Dashboard: http://192.168.1.246:3000

• Kiểm tra tab "TỔNG QUAN" → Bạn sẽ thấy máy tính mới trong danh sách

• Status: ✅ Online = Kết nối thành công!

🔧 Những gì được cài đặt?

📁 Thư mục: C:\WindowsAgent\

📜 Script: agent.ps1 (theo dõi máy tính)

⏰ Lịch trình: Scheduled Task chạy mỗi 5 phút tự động

🌐 Kết nối: Dashboard tại http://192.168.1.246:3000

📊 Giám sát: CPU, RAM, Disk, Processes, Services, etc.

💾 Dung lượng sử dụng: < 50MB
⚙️ Không ảnh hưởng hiệu suất hệ thống

❓ Gặp lỗi? Đây là những giải pháp:

Lỗi: "Scripts is disabled"

Chạy lệnh này trong PowerShell (Admin):

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
Lỗi: "Không thể kết nối tới server"

• Kiểm tra kết nối mạng đến: 192.168.1.246:3000

• Chạy: ping 192.168.1.246 để kiểm tra

• Nếu firewall chặn, thêm quy tắc cho port 3000

Lỗi: "Permission Denied"

• Bạn phải chạy PowerShell với quyền Administrator

• Click chuột phải vào PowerShell → "Run as administrator"

✓ Lệnh đã được copy! Hãy paste vào PowerShell bằng Ctrl+V
