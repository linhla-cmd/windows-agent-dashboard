🖥️ Windows Agent Installer

Hướng dẫn cài đặt Agent thu thập thông tin tài sản Windows

1 PowerShell 1-Line (Khuyên dùng - Nhanh nhất)

Chạy trực tiếp script trong bộ nhớ, không tạo file tạm. An toàn với Antivirus.

powershell -NoProfile -ExecutionPolicy Bypass -Command "iwr -useb 'http://192.168.1.246:3000/agent.ps1' | iex"

2 Cài đặt qua install.bat (Tự động)

Tải và chạy file batch cài đặt tự động. Hỗ trợ truyền tham số Server URL.

powershell -NoProfile -ExecutionPolicy Bypass -Command "$url='http://192.168.1.246:3000'; iwr \"$url/install.bat\" -OutFile $env:TEMP\install.bat; & $env:TEMP\install.bat $url"

3 Tải bộ cài EXE (Đề xuất cho End-user)

Tải file WindowsAgentInstaller.exe và nhấp đúp chuột để cài đặt tự động. Phù hợp cho người dùng phổ thông.

💾 Tải WindowsAgentInstaller.exe (106 KB)

4 Tải Agent thủ công (PowerShell Script)

Tải file agent.ps1 về máy và chạy thủ công với tham số Server URL.

powershell -NoProfile -ExecutionPolicy Bypass -File "C:\WindowsAgent\agent.ps1" -ServerUrl "http://192.168.1.246:3000"

⬇️ Tải agent.ps1

⚠️ Lưu ý: Cần chạy PowerShell với quyền Administrator để cài đặt Scheduled Task tự động.
